# Interactive 3D molecule browser (`docs/`)

Self-contained web viewer for ADT's scaffold-conditional 3D generations.
This directory **is** the GitHub Pages site for the repository: once Pages is
enabled it is served at <https://tkotani.github.io/ADT/>.

## What it shows

`index.html` links to one page per scaffold (benzene, pyridine, pyrimidine,
pyrazine, furan, thiophene, cyclohexane). Each page contains **50 XVR-positive
molecules** generated by the single 30-atom ADT model when prompted with that
ring. Press **Play** (or `Space`) to watch the molecule grow one heavy atom at a
time, in the autoregressive order the model emitted it, starting from the fixed
scaffold ring. The coordinates are the raw network output (pre-xTB).

Controls: `Space` play/pause · `r` replay · `←`/`→` switch molecule ·
drag to rotate · lower slider scrubs the growth frame by hand.

Each `*.html` is **fully self-contained** (3Dmol.js and all coordinates are
inlined). You can also just download a single file and open it offline — no
server, no network.

## Viewing locally

Open any file directly in a browser:

```bash
xdg-open index.html        # or: open index.html  (macOS)
```

## Enabling GitHub Pages

On GitHub: **Settings → Pages → Source: "Deploy from a branch" → Branch:
`main` / folder: `/docs`**. The site appears at
`https://<user>.github.io/<repo>/` within a minute.

## Regenerating the pages

The pages are produced by `export_html.py` from per-scaffold SDF files.
`3Dmol-min.js` **must sit next to `export_html.py`** so the library is inlined
into the output (otherwise it falls back to a CDN `<script>` tag and needs a
network connection).

The source molecules are the first 50 of each scaffold's
`mol_stable_kekulized.sdf` (the XVR-positive, kekulized set) from the evaluation
output. The 50-molecule SDFs used here are kept in `data/` for offline
reproducibility; to rebuild them from the full evaluation output:

```bash
# from ADT_ROOT (the repo root)
SRC=Drugs/data/freeorder_v26/v26s_scaffolds_n10k
for s in benzene pyridine pyrimidine pyrazine furan thiophene cyclohexane; do
  awk 'BEGIN{n=0} {print} /\$\$\$\$/ {n++; if(n>=50) exit}' \
    "$SRC/$s/mol_stable_kekulized.sdf" > docs/data/${s}_50.sdf
done
```

Then regenerate the HTML (scaffold ring size: 6 for the six-membered rings,
5 for furan and thiophene — this sets how many leading atoms form the first
frame):

```bash
cd docs
declare -A SZ=( [benzene]=6 [pyridine]=6 [pyrimidine]=6 [pyrazine]=6 \
                [furan]=5 [thiophene]=5 [cyclohexane]=6 )
for s in benzene pyridine pyrimidine pyrazine furan thiophene cyclohexane; do
  python3 export_html.py data/${s}_50.sdf -n 50 --stable \
    --scaffold-size ${SZ[$s]} --frame-ms 200 -o ${s}.html
done
```

Requires only `rdkit` and `numpy` (no GPU, no torch for SDF input). E.g.:

```bash
uv run --with rdkit --with numpy --no-project python3 export_html.py ...
```

## `export_html.py` options

| flag | meaning |
|---|---|
| `inputs` | one or more `.sdf` / `.sdf.gz` files (or a generation `.pt`) |
| `-n N` | cap at N molecules (default 500) |
| `--stable` | keep only valence-stable molecules (SDF input is pre-filtered, so this is a no-op safeguard) |
| `--scaffold-size N` | leading atoms shown in the first growth frame (ring size) |
| `--frame-ms MS` | milliseconds per growth frame (default 250) |
| `--shuffle` / `--seed` | randomise molecule order |
| `-o FILE` | output HTML path |

## Files

| path | description |
|---|---|
| `index.html` | landing page linking the seven scaffolds |
| `<scaffold>.html` | self-contained viewer, 50 molecules each |
| `data/<scaffold>_50.sdf` | source SDF (first 50 XVR-positive molecules) |
| `export_html.py` | SDF → self-contained HTML generator |
| `3Dmol-min.js` | bundled [3Dmol.js](https://3Dmol.org) (inlined at generation time) |
